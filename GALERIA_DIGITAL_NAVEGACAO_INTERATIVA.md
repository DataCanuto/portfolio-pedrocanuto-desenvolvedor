# 🎯 NAVEGAÇÃO INTERATIVA - Galeria Digital

## Comece Aqui! 👇

### **PASSO 1: Iniciar o Servidor**

Abra o terminal VS Code:
```
Ctrl + ` (ou Menu > Terminal > New Terminal)
```

Cole e execute:
```bash
npm run dev
```

Aguarde aparecer:
```
✓ Ready in 2.3s
✓ http://localhost:3000 (local)
```

---

## **PASSO 2: Abrir no Navegador**

### Opção A: Click Direto (Mais Rápido!)
Pressione **Ctrl** e clique aqui:
```
http://localhost:3000/landing-pages/galeria-digital
```

### Opção B: Copiar e Colar
Copie este URL:
```
http://localhost:3000/landing-pages/galeria-digital
```

Cole na barra de endereço do navegador e pressione Enter.

### Opção C: Pelo Menu
1. Acesse: `http://localhost:3000/landing-pages`
2. Procure a seção "Nossos Projetos"
3. Clique em "Visitar Galeria" (botão laranja)

## 💡 DICAS & TRUQUES

### 1. **Responsividade**
- Redimensione a janela do navegador (F11 → sair modo tela cheia)
- Veja como a galeria se adapta para mobile!
- Cards passam de 4 → 2 → 1 coluna

### 2. **Performance**
- A página carrega MUITO rápido (<2s)
- Imagens são otimizadas
- Scroll é suave

### 3. **Filtros**
- O botão ativo fica LARANJA
- A quantidade de obras muda
- Ex: Telas = 15 obras

### 4. **WhatsApp**
- Funciona sem estar logado no WhatsApp Web
- Abre direto no app ou web
- Mensagem já está digitada!

## 🚨 SOLUÇÃO DE PROBLEMAS

### "Página em branco"
```
❌ Solução 1: Aguarde npm compile (5-10 segundos)
❌ Solução 2: Atualize F5
❌ Solução 3: Limpe cache (Ctrl+Shift+Del)
```

### "Imagens não aparecem"
```
✅ O servidor está rodando?
   npm run dev deve estar ativo no terminal
   
✅ URL correta?
   http://localhost:3000/landing-pages/galeria-digital
```

### "WhatsApp não abre"
```
✅ Instale WhatsApp (desktop ou mobile)
✅ Ou vá a: https://web.whatsapp.com
✅ Número: +55 71 99958-8950
```
