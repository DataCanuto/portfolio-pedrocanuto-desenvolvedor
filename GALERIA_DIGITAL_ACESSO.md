## 🚀 COMO ACESSAR - PASSO A PASSO

### **PASSO 1: Iniciar o Servidor**

Abra o terminal integrado do VS Code:
```
Ctrl + ` (ou Menu > Terminal > New Terminal)
```

Execute:
```bash
npm run dev
```

**Aguarde a mensagem:**
```
✓ Ready in 2.3s
```

---

### **PASSO 2: Acessar a Galeria**

#### **Opção A: Link Direto** (MAIS RÁPIDO)

Clique neste link enquanto o servidor roda:
```
http://localhost:3000/landing-pages/galeria-digital
```

**OU** Digite na barra de endereço do navegador:
```
localhost:3000/landing-pages/galeria-digital
```

#### **Opção B: Pelo Menu**

1. Acesse: `http://localhost:3000/landing-pages`
2. Role até "Nossos Projetos"
3. Clique no botão "Visitar Galeria" (laranja)

## 🎯 O QUE FAZER NA PÁGINA

### 1️⃣ **Seção Hero (Topo)**
   - Título: "Um Olhar Investigativo sobre a Cidade"
   - Veja as 3 estatísticas
   - Clique em "Explorar Galeria" para scroll automático

### 2️⃣ **Filtrar Obras** (Menu Sticky)
   - Clique em "Todas as Obras" para ver tudo
   - Clique em "🎨 Telas" para ver apenas telas
   - Clique em "💨 Aerografias" para arte urbana
   - Clique em "✏️ Desenhos" para desenhos
   - Clique em "🔧 Dobraduras" para esculturas
   - Clique em "👕 Camisetas" para arte vestível

### 3️⃣ **Explorar Obras**
   - Veja cards em grid (4 colunas no desktop, 2 no tablet, 1 mobile)
   - Passe o mouse para zoom automático
   - Clique no ❤️ para favoritar (muda de cor!)

### 4️⃣ **Ver Detalhes Completos**
   - Clique em qualquer card para abrir modal
   - Veja imagem em alta qualidade
   - Informações: Técnica, Ano, Dimensões, Preço, Status
   - Clique no botão "💬 Contatar via WhatsApp"
   - Uma mensagem pré-formatada será enviada para Paulo

### 5️⃣ **Contatar o Artista**
   - 3 formas de contato:
     - ✅ Via card (botão WhatsApp rápido)
     - ✅ Via modal (botão de contato)
     - ✅ Via seção "Sobre Paulo Canuto" (botões verdes/laranja)
   - **Número**: +55 71 99958-8950

### 6️⃣ **Conhecer o Artista**
