# 🎨 Portfólio Digital - Pedro Canuto

Portfólio completo de desenvolvedor de sistemas com integração de galeria digital de artes de Paulo Canuto.

## 🚀 Características

- **Next.js 14** - App Router com performance otimizada
- **React 18** - Componentes modernos com Hooks
- **TypeScript** - Tipagem segura e robusta
- **Tailwind CSS** - Design responsivo e elegante
- **Framer Motion** - Animações fluidas e profissionais
- **Responsive Design** - Funciona em todos os dispositivos

### Páginas Principais
- **Home** - Apresentação do desenvolvedor

- **Projects** - Projetos principais
- **Services** - Serviços oferecidos
